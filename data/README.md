# Data Directory Guide

This directory contains the raw, processed, and sample datasets for the **Credit Risk Modelling** project.

## Directory Structure

```
data/
├── raw/                                  # Raw external data (git-ignored)
│   ├── application_train.csv             # Primary dataset (~152 MB, 307,511 rows x 122 features)
│   └── HomeCredit_columns_description.csv# Data dictionary (column definitions)
├── processed/                            # Engineered parquet splits (git-ignored, generated by run_experiment.py)
│   ├── engineered_train_2018_2019.parquet# Temporal training window (205,007 rows)
│   └── engineered_test_2020.parquet      # Out-Of-Time test cohort (102,504 rows)
└── sample/                               # Lightweight sample for testing (tracked in Git)
    └── sample_application_train.csv      # 1,000-row stratified sample (~520 KB)
```

## Dataset Overview

The dataset comes from the **Home Credit Default Risk** competition on Kaggle. Each row represents one loan application to Home Credit.

- **Primary File:** `application_train.csv` (307,511 rows × 122 columns)
- **Target Variable:** `TARGET`
  - `0`: Applicant repaid loan on time (91.93%)
  - `1`: Applicant had payment difficulties / default (8.07%)
- **Imbalance Ratio:** ~11.39 : 1

## Acquisition

### 1. Zero-Download Fast Quickstart
For rapid testing or verification without downloading 152 MB:
```bash
# Use data/sample/sample_application_train.csv directly
```

### 2. Full Dataset Download
Using the provided helper script:
```bash
python scripts/download_data.py
```

Or manually via the Kaggle CLI:
```bash
kaggle competitions download -c home-credit-default-risk -f application_train.csv -p data/raw/
```
Unzip the resulting archive directly into `data/raw/`.

## Data Governance & Preprocessing Notes

1. **Strict Temporal Partitioning:**
   - Training cohort: Applications from 2018–2019 (205,007 rows, 8.12% default).
   - Validation cohort: Applications from 2020 (102,504 rows, 7.98% default).
2. **Sentinel Value Correction:**
   - `DAYS_EMPLOYED = 365243` represents an anomaly/placeholder (1000 years, pensioners/unemployed). It is replaced with `NaN` and flagged via `DAYS_EMPLOYED_ANOM`.
3. **Winsorization:**
   - Extreme income outliers are capped at the 99.9th percentile ($900,000) computed **exclusively on the training window** to prevent data leakage.
